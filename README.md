# 🎮 Dịch Phụ Đề Game

Đọc phụ đề tiếng Anh trong game và dịch sang tiếng Việt bằng AI Gemini (miễn phí), hiện chữ to và đọc to bằng giọng Việt.
Có bản cho **Windows** và **macOS**.

## ⬇️ Tải app
**[Bấm vào đây để tải bản mới nhất](https://github.com/HoangTran4869/DichPhuDeGame/releases/latest)**, rồi chọn file:

| Máy của bạn | Tải file này |
|---|---|
| 🪟 **Windows 10/11** | `DichPhuDeGame_Windows_Setup_v1.0.0.exe` (khoảng 94 MB) |
| 🍎 **macOS** (chip Apple M1 trở lên) | file có đuôi **`.dmg`** |

---

## 🪟 Windows

### Cần có
- Windows 10 hoặc 11 (64-bit)
- Tài khoản Google để lấy mã Gemini miễn phí
- Chơi PS5/console: cần **capture card** cắm vào máy tính. Xem YouTube, phim, game trên máy tính thì không cần.

### Cài đặt
1. Bấm đúp file **DichPhuDeGame_Windows_Setup_v1.0.0.exe**.
2. Nếu Windows hiện màn hình xanh **"Windows protected your PC"**: bấm **More info** → **Run anyway**.
   (Windows cảnh báo vì app chưa mua chứng chỉ, chỉ cần làm 1 lần.)
3. Bấm **Next** → **Install**, xong bấm **Finish** là app mở lên. Trên Desktop có biểu tượng app.

### Lần đầu dùng
1. Nhập **mã Gemini** theo hướng dẫn trong app (nên có 2–3 mã).
2. Chọn nguồn hình:
   - **🎮 Capture card (PS5, console)**: app mở toàn màn hình.
   - **🖥 Màn hình máy tính**: dịch phụ đề YouTube, phim, game ngay trên máy tính.
3. Kéo khung quanh chỗ có phụ đề → nhấn **Enter**.
4. Muốn nghe đọc tiếng Việt: bấm **Đọc to**. Nếu máy chưa có giọng Việt: **Settings → Time & language → Language & region → Add a language → Vietnamese** (chỉ cần tick **Text-to-speech**).

## 🍎 macOS

### Cài đặt
1. Mở file **.dmg** vừa tải, **kéo biểu tượng app** vào thư mục **Applications**.
2. Lần đầu mở: vào **Applications**, **chuột phải** vào app → **Mở (Open)** → bấm **Mở** lần nữa.
   Nếu vẫn không mở được: **Cài đặt hệ thống → Quyền riêng tư & Bảo mật** → bấm **Vẫn mở (Open Anyway)**.
3. App hỏi **mã Gemini** và quyền **Camera** (capture card được coi như camera) → bấm **Cho phép**.
